# Career Catalyst (Django)

## Project Goal

Career Catalyst is a career guidance platform built using Django that helps students with career planning, resume building, AI assistance, and skill development.

---

## Tech Stack

Backend:
- Django
- Django REST Framework

Database:
- PostgreSQL

Frontend:
- HTML
- CSS
- Bootstrap 5
- JavaScript

Deployment:
- Docker
- Render

Version Control:
- Git
- GitHub
