# UI Guidelines

## Design Philosophy

Career Catalyst follows a clean, modern, and minimal design inspired by professional SaaS applications. The interface should prioritize usability, accessibility, and consistency while providing an engaging user experience.

---

## Design Principles

- Clean and uncluttered layouts
- Consistent spacing and typography
- Responsive across desktop, tablet, and mobile devices
- Accessible and user-friendly
- Fast loading with optimized assets
- Reusable UI components

## Buttons

### Primary Button

- Blue background
- White text
- Rounded corners
- Hover animation

### Secondary Button

- White background
- Blue border
- Blue text

### Danger Button

- Red background
- White text

---

## Cards

Cards should have:

- White background
- Soft shadow
- Rounded corners
- Padding of 24px
- Smooth hover effect

---

## Forms

All forms should include:

- Floating labels (optional)
- Proper validation
- Error messages
- Success indicators
- Consistent spacing

---

Navbar should include:

- Smooth hover effects
